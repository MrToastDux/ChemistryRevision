# Chemistry Sprint - Grade 10 Paper 2

A basic Duolingo-style revision app covering your eight supplied chemistry topics.

- 16 lessons and 160 automatically checked practice questions
- XP, refillable hearts, saved lesson progress and mistake review
- A full printable revision guide and quick reference
- Lewis diagrams, a schematic heating curve and an orbital diagram
- A 100-mark original mock paper with 10 multiple-choice marks, numerical questions, written explanations, drawings and a worked memo
- Mock numeric/MC checks are provisional: mark your written work and method marks using the provided rubric

## GitHub Pages setup

1. Extract the ZIP.
2. Create a repository, for example Chemistry.
3. Upload the CONTENTS of this folder to its top level: index.html, README.md and .nojekyll. Do not upload the ZIP itself or nest index.html in another folder.
4. Commit to main.
5. Open Settings > Pages > Build and deployment. Choose Deploy from a branch, then main and /(root), and Save.
6. Wait for deployment. Settings > Pages will show your site URL. A normal project address looks like https://YOUR-USERNAME.github.io/Chemistry/.

If the website only shows the repository title/README, verify that index.html is at the publishing root, not inside a subfolder.

No installation, build command, account, API keys or external files are required. You can also double-click index.html to use it offline. Browser printing can save the guide, paper or memo as PDF.

Lesson progress is stored in localStorage in this browser and is separate from Physics. It will not sync between devices or origins. Mock-exam answers and self-marked scores persist only during the current page session; reloading clears them.

All lessons are unlocked. Losing five hearts does not lock you out: read the worked explanation, then refill and continue. Numeric input accepts decimal points, decimal commas and scientific e notation; where a coefficient is requested, enter only that coefficient.

## Scope and constants

Original revision content checked against the DBE Grade 10 teaching-plan topics. Your teacher's scope and data sheet take priority. This is not an official exam. The mock is 100 marks with a suggested two-hour duration, chosen for practice.

Use the given rounded school atomic masses, Avogadro constant 6.02 x 10^23 mol^-1, and conventional school STP (0 degrees C and 101.3 kPa) molar gas volume 22.4 dm^3/mol for these exercises. Limiting-reactant and dilution discussions are labelled extensions.
